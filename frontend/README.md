# Frontend - Gestionale HERA S.p.A.

Applicazione web e mobile (Android via Capacitor) sviluppata con React, Tailwind CSS e componentistica personalizzata.

## Script Disponibili

Nel percorso `frontend`, puoi eseguire:

### `yarn start`
Avvia l'applicazione in modalità sviluppo su [http://localhost:3000](http://localhost:3000).

### `yarn build`
Compila l'applicazione per l'ambiente di produzione all'interno della cartella `build/`.

### `yarn cap sync`
Sincronizza gli asset compilati di React con il progetto Android nativo (`android/`).
